# 📚 Library Management System

A web-based **Library Management System** developed to simplify and manage common library operations such as book management, member management, issuing and returning books, loan tracking, reminders, reports, and e-library resources.

## 📌 Project Overview

The Library Management System provides a simple and user-friendly interface for managing library activities digitally. It helps maintain book and member records while making operations such as issuing and returning books easier to manage.

## ✨ Features

* 📖 Book Management
* 👥 Member Management
* 📤 Issue Books
* 📥 Return Books
* 📋 Loan Management
* 🔔 Reminders
* 📊 Reports
* 💻 E-Library
* 🔐 Login System
* 📚 Library Dashboard
* 🗂️ Library data management using JSON

## 🛠️ Technologies Used

* **Python** – Backend and application logic
* **HTML** – Web page structure
* **CSS** – Styling and user interface
* **JSON** – Data storage

## ⚙️ How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/library-management-system.git
```

### 2. Open the Project Folder

```bash
cd library-management-system
```

### 3. Install Required Dependencies

If the project uses any external Python libraries, install them using:

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python library.py
```

Then open the local URL provided by the application in your web browser.
